#📝 Smart Task Manager

A console-based task management application built using Java.
The application allows users to create, manage, track, and save tasks through an interactive command-line interface.

##🚀 Features
➕ Add new tasks
👀 View all tasks
✅ Mark tasks as completed
🔍 Search and manage tasks
🗑️ Delete tasks
📊 View task statistics
📅 Set task deadlines using LocalDate
🔥 Assign task priorities: HIGH, MEDIUM, or LOW
💾 Save tasks to a local file
📂 Automatically load previously saved tasks when the application starts
🎨 Interactive console interface

##🛠️ Technologies Used
Java
Object-Oriented Programming (OOP)
ArrayList
LocalDate
File Handling
Exception Handling
Git and GitHub
